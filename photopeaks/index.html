ABSTRACT

本文做了什么

PhotoAgent（Yao et al., ICML 2026）把图像编辑建模为闭环美学规划，方向正确，但有两个部署级瓶颈： 规划成本（MCTS 的每次模拟都真实执行扩散编辑，论文附录 F 报 470 秒/张）与 目标退化（四个指标的加权标量 + 单调接受回退，把高维审美压成一条坐标轴，风格在平均中趋于平庸）。 本文给出两处结构性修改与一次 27 张真实照片的对照实验。

C1 · 预测式评判（Predictive Judge）

用一次 VLM 调用预测候选概念的编辑结果与四维得分，取代"执行后再评估"的 rollout。 规划期的扩散生成次数从约 60 次降到 0，规划耗时 250s → 16.5s。

C2 · 概念级多峰规划（Concept-level Peaks）

搜索单元从原子动作（更亮/更艳/加对比）改为完整风格方向（胶片暖调/冷调极简/戏剧化…）。 分支之间硬隔离、不做任何得分或参数平均；终选允许判定"原图最好"。

C3 · do-no-harm 门禁

本地 CLIP 内容保持校验（阈值 0.55）+ 可回滚，配合"原图最好"的终选，杜绝无谓编辑。

为什么标量目标会毁掉风格——一个直接实验

PhotoAgent 的评估器是四个指标的加权和（CLIP×1.0 + LAION 美学×2.0 + ImageReward×2.0 + UGC 奖励×0.8，归一化 5.8）， 再配合"分数不涨就回滚"的单调接受。结果：所有编辑轨迹被迫沿同一坐标轴爬坡。 用同一张照片的两个真实分支做一个直观实验：把两个峰做像素平均，看它的美学分落在哪。

METHOD · DETAILS

四个模块的设计与三条硬规则

Perceiver — 概念生成

输入图像 + 可选意图（情绪/氛围级，非具体物体）；输出 3–5 个概念。Prompt 级强约束： 概念必须两两互斥，若两个方向会产出相似结果则必须替换其中之一；概念内步骤必须自洽（不混合风格）； 人像场景禁止任何改变身份的操作；照片已足够好时允许提出克制方案。 

{ "scene_type": "portrait | landscape | ...",
  "concepts": [
    { "name": "warm film nostalgia",
      "rationale": "why this fits THIS photo",
      "style_keywords": ["warm","grainy","soft"],
      "steps": ["concrete instruction", "..."] } ] }

Judge — 预测式评判

对每个概念做一次调用，输出四个维度（1–5）与一句判断：aesthetic_gain、 style_coherence、feasibility、fidelity_risk，并按 gain + 0.5·coherence + 0.5·feasibility + 0.5·fidelity 合成效用。 规则明确要求：对"只提亮/只加饱和"的通用概念严格压分；概念内步骤互相冲突要扣风格一致性。

Executor — 分支并行、链式执行

只执行 top-K（默认 2）概念；每个概念在自己的分支里顺序执行 1–3 步，双分支并发（线程池）。 分支之间不交换任何信息——这是"多峰"概念的工程化：没有跨分支的平均，就没有风格折中。

可选扩展：执行器是抽象接口，可替换为任意编辑后端（本地模型 / 其他 API）， 本仓库默认使用 DashScope qwen-image-edit，并预留 OpenAI 兼容端点。

Gate & Pick — 安全网与终选

门禁用本地 CLIP（ViT-B/32）计算编辑前后内容相似度，低于 0.55 视为破坏内容，分支作废； 终选把原图与各分支成品一起交给 VLM 比较，允许输出"0 = 原图最好"。 两个机制共同回答"什么时候不该动手"——这正是 PhotoAgent 失败案例（其 Fig.13）暴露的缺口。

契约字段：Gate 输出 {content_sim, aes_in, aes_out, passed}； Pick 输出 {best: 0..K, reason}。全流程无隐藏状态，每步可复现。
EXPERIMENTS

27 张真实照片，三种策略对照

数据全部来自本人拍摄的 27 张随手拍（Lightroom 导出，人物 / 风光 / 城市 / 夜景 / 食物等混合场景）， 在同一 API 与同一分辨率下跑三种策略：single = 一把梭通用指令； scalar = 原子动作 + 标量打分选优（PhotoAgent 思想的最小复现）； peaks = 本文完整流程。

被判"不该动手"的情况

当所有分支都被门禁否决，或终选判定原图最好时，系统输出原图并说明理由—— 这在 PhotoAgent 的框架里很难发生（分数不涨即回滚，但仍会保留最后一次"微涨"的编辑）。 本次捕获运行中两个分支均通过门禁；而在 27 张对照里，peaks 的保守分支（内容保持更高的一项） 多次成为终选，说明"少改"与"改对"并不冲突。

失败边界（不做粉饰）：暗光与低质量输入仍会失效（VLM 看不清内容、编辑模型放大噪声）； 人像的身份保持依赖编辑模型自身能力，门禁只能发现严重破坏而不能保证细节一致； 美学评分本身带有的文化偏好未被建模——这是下一步工作（个性化奖励）的入口。
DISCUSSION

为什么"多峰"是结构性的，而不是技巧

在进入这个项目之前，我做过一个 RAW 胶片模拟 / 色彩风格迁移系统（106 参数可微调色管线 + 参考集上的核能量风格模型）。 它的风格迁移版本因为同一个原因失败：风格空间里的朴素平均会让输出变灰、变脏。 我当时的修正与这里一致——把参考集聚成 2–4 个"风格头"，输入稀疏路由到单一头部， 头间影调轴差异过大时禁止软混合；而最终稳定可用的形态是逐片种从光谱数据烘焙的单峰 3D LUT， 因为它彻底消除了平均。

因此当我在 PhotoAgent 中看到"加权标量 + 单调接受"时，认出的是同一个失败模式高了一层： 从特征空间搬到了决策空间。这也解释了为什么简单的加权和无法替代"多峰"： 在奖励模型的平均口味附近，任何两个方向的插值点都不是两个峰中较差的那个，而是谷底。
