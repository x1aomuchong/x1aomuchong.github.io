01ABSTRACT

做了什么

PhotoAgent 把修图当成多步决策来做，方向是对的，但有两个硬伤：贵—— 规划时每试一个动作都要真的跑一次扩散模型，论文自己报了 470 秒一张； 窄——四种评估指标加权成一个分数再取最大，等于逼着所有编辑走同一条路，风格被平均掉。

C1

先预测，再执行

每个候选方向只让视觉模型看一眼原图，给出预测分，不再"跑一遍看看"。本实现规划期生成 0 张、规划耗时 16.5 秒（论文报告其默认配置为约 60 次生成、规划约 250 秒）。

C2

按风格方向搜索，而不是按动作

候选单位从"提亮/加饱和"这类动作，换成"胶片暖调""冷调极简"这类完整方向。K 条链路各做各的（本次运行 K = 2），分数和参数都不互相混合。

C3

允许不改

终选可以判定"原图最好"；另有内容保持门禁，改动破坏画面时整条分支作废。

02METHOD

闭环多峰搜索
提方向 → 取 Top-K → 并行执行 → 评估 → 继续或退出

架构里不写死任何数量：每轮从当前状态提出 n 个互斥风格方向，预测式打分后按效用取 Top-K； K 条链路并行执行（硬隔离，彼此不交换任何信息），过内容门禁后由评估器在「当前状态 + K 个结果」里比较式评优。 当前状态胜出就退出——第 1 轮退出即"原图最好，不改"；否则胜者成为下一轮的起点，直到 R 轮上限。

模块之间传的是结构化字段，不是自由文本；成本是实测的。数量一律用记号（n / K / s），具体取值只出现在"本次运行配置"里。

04PROCESS

处理一张照片的四步
这是"一轮"的样子，闭环可以走多轮

1

想方向

让模型提出 n 个互不相同的风格方向（n 是可调参数，示例 n = 5；比如胶片暖调、冷调极简、戏剧化）。 像"提亮一点"和"再亮一点"这类同义方向会被要求重写；拍人的照片不许改动脸。

2

先算不做

每个方向只让模型看一眼当前图像，给出预测分：值不值得做、会不会伤画面。 这一步不生成任何图片，也是成本能降下来的原因。

3

各做各的

只做效用最高的 K 个方向（K ≤ n，示例 K = 2），各自在自己的链路里执行、同时进行，互不交流—— 不混合分数，也不混合参数。中间地带就是这么被绕开的。

4

挑一张，或者不改

把当前状态和 K 个成品放在一起比较，允许直接判"当前状态最好"：第 1 轮就是"原图最好"，直接退出； 否则胜者成为下一轮的起点，最多走 R 轮。另有内容保持检查——改动破坏了画面，整条链路作废。

判定"不该动手"的情况

所有分支都被门禁否决，或者终选认为原图更好时，系统就交回原图。这在 PhotoAgent 的结构里不容易发生： 它只要分数涨一点点就会保留那次编辑。27 张对照里，peaks 多次把保守分支选为最终结果——少改和改对并不矛盾。

06ROBUSTNESS

如果不加约束，会出什么问题

生成式编辑的特点是：你不约束它，它就会自由发挥。有四件事必须提前挡住。

不锁内容 → 模型会"加戏"

指令里出现"氛围""层次"，它就可能真的去画前景、加光晕。 做法：每条指令带保持性要求，概念层面禁止"添加类"步骤，门禁用边缘结构相关性复核。

0.40 → 0.99结构相关性（1.0 = 画面几何完全没动）

不锁肤色 → 人像被整体染色

"暖光""日落感"这类词很容易把整张图推向橙红，风景还好，脸就明显不对。 做法：概念阶段锁定肤色与身份，融合时只从原片取纹理、不碰颜色。

0.86 → 0.95内容相似度 · 色度噪声 3.2 → 1.17

不做细节融合 → 修完比原图还糊

编辑接口固定返回约 130 万像素，而原片是 2400 万像素，一步接一步重画还会继续掉细节。 做法：影调和颜色取编辑结果，纹理从原片高频补回。

0.21 → 1.00分辨率保留 · 细节能量比 0.97

只看一个总分 → 拦不住局部的坏

全局相似度看的是"还是不是那张图"，局部多画几片叶子、脸偏一点色，它几乎不扣分。 做法：三个本地指标交叉检查（内容相似度、结构相关性、高频色度噪声），越界即整条分支作废。

实测：通用编辑模型的指令遵循并不可靠

前面那些约束都是绕路。为了弄清根因，我用同一张照片做了单步对照实验：只改指令措辞，其余不变，看输出的整体色彩偏移。

"稍微锐化"（不含颜色词）≈ 0≈ 0≈ 0
"提高中间调对比"（纯影调）+3 ~ +12+3 ~ +9−34 / +9

两组数字分别对应两张测试照片（猫、城景）。中性指令下模型几乎是忠实的； 一旦出现"暖/冷/色温"，它就会把整幅图推走 50–80 个单位的暖冷偏移，把饱和度抬高三四十， 而且完全无视"稍微"这类程度限定。

结论很直接：通用编辑模型做不到"理解意图并按合适的幅度修改"——它只会做"大动作"。 我们能在规划层禁掉色温类步骤、能用门禁兜底，但这是在躲问题。 要让系统稳定，重新训练执行器是必须的，不是优化项。

07OUTLOOK

下一步：换掉执行器，再让它懂人

前面测出来的问题决定了下一步：模型层要重训，数据通路要换到 RAW，编辑的作用范围要从"整幅图"收到"语义区域"。

01

重训执行器——把"重画像素"换成"预测参数"

扩散编辑模型不是必须的。在这套系统里它只是执行器——负责把"想法"落到像素上， 换成别的东西也不影响整个流程。而且论保真度，扩散本身是偏差的：伪色、模糊、鬼影是它的固有毛病， 靠提示词和门禁只能压制，压不掉。

正确的做法是训练一个专用调色模型：输入图像与风格向量，直接输出调色参数 （白平衡、曝光曲线、混色、饱和度、分离色调）。参数化的执行器天然可控——不重画就没有伪色、模糊和鬼影， 分辨率无损、内容零幻觉，幅度可以按参数精确约束，不会像通用模型那样"一说暖就推 80 个点"。 这既是保真问题，也是指令遵循问题。

训练不需要人工标注的成对数据，思路是把风格打烂，再按向量复原：收集大量无标注的优秀作品 （同一风格的语料只需要好片，不需要坏片）→ 用 VLM 编码出风格向量 v → 在线性空间做可逆扰动、 把作品的风格彻底打烂，得到输入 J → 训练执行器从 (J, v) 反推参数。 关键在扰动已经把 J 的风格毁掉，所以目标风格的唯一通道就是 v——梯度会强制模型真的用它， 它不可能把风格向量学成摆设。

四条设计规则，每条都对应上文一个实测到的失败模式

规则为什么必须这样
扰动可逆、且明显坏硬裁切丢信息，最优解退化成条件均值——"平庸"会从这扇门回来；在线性空间用软拐点，不硬裁切
风格不能与扰动互相冒充若某种扰动的样子≈某个合法风格，(J, v) 就有两种自洽解释，解被平均；扰动走"明显坏"，语料走"明显好"
掺入 δ = 0 与微扰样本恒等是合法输出，"允许不改"免费得到，执行器部署时天然支持"原图最好"
参数以中性为原点λ·θ 是数学上精确的"稍微"（实测通用模型完全无视"稍微"）；多峰还能在参数层做凸组合

风格通道对齐：决定整套系统是否自洽

训练时 v 来自成品图，上线时 v 必须由 perceiver 产出、且落在同一个空间。做法是把语料先做风格聚类， 潜空间定义为"簇质心 ＋ 对比学习出的连续维度"，perceiver 只在该空间里输出（分类 ＋ 回归到簇的组合）： 多峰天然成立，它的 SFT 监督还能从"照片 ↔ 风格簇"的匹配统计自动 bootstrap。 剩下的"哪一簇更好看"才是审美偏好问题——那才是真正需要人类数据的地方，也就是出路二。

怎么验证：三个指标，全部无循环

先用 MIT-Adobe FiveK 做小规模真实配对验证：输入取 RAW 的中性渲染，目标取五位专家各自的成片， v 取该专家的风格向量——5000 张 × 5 种风格，天然是多峰监督，零标注成本；跑通"换 v → 输出真的变"， 就证明风格通道被用上了。扰动语料在这之后上，扩的是覆盖面，不是正确性。 指标用扰动恢复误差、向量互换灵敏度、参数与真实预设的一致性——全部不碰 reward 模型， 正好避开前面批评过的那条循环。

训练好的执行器在缩略图上就能预测参数，全分辨率只是渲染：端到端毫秒级、零 API 依赖、参数可解释可回滚， 门禁的负担也随之小得多。

02

用真人反馈微调感知与评判

"想方向"和"打分"现在靠通用模型撑着，审美判断偏平均、也偏保守。 这里没有通用解：审美是多元的——同一张照片有好几种都成立的风格，有时互相冲突； 审美也是主观的。任何系统能做的最多只是向人类偏好的 ground truth 拟合，偏好数据越多，拟合得越准。

这需要大量人类反馈（成对比较最省成本），所以放在第二阶段：先让执行器可控，再让它懂你。 两条出路在这里合流：执行器训练里唯一缺的那块监督，就是"哪个方向更好看"。

换掉执行器之后：收益与接口

  • 推理毫秒级、零 API 依赖，"贵"这个问题从根上消失；
  • 参数可解释、可回滚、可审计——每一步都能说清"改了什么、改了多少"；
  • 分辨率与结构问题不存在：参数作用于原图，不重画；
  • 决策层不需要改一行：多峰探索、先预测再执行、允许不改，与执行器无关，原样可用。

评测也因此变干净：风格有没有被遵循，可以在参数层直接度量，而不是靠一个同时也在回路里的打分模型。

03

从 JPEG 转到 RAW——这是实用化的前提

JPEG 是相机处理完的结果：8 位、有压缩、高光已经截断、白平衡和影调曲线已经烧进像素。 在它上面修图，本质是在改"已经定稿的画"——暗部一拉就出色带和噪点，高光没有可恢复的信息， 大范围调色最容易出伪色和后相化。今天看到的大部分瑕疵，根子都在这里。

要真正实用，必须做 RAW 适配：接 12–14 位线性数据，在去马赛克之后的宽色域空间里做曝光、 白平衡和曲线，最后一步才输出 JPEG。这样高光能找回来、肤色不容易崩、调色的余量大一个数量级。 我之前的胶片模拟系统就是按 RAW 管线做的，迁移到这里并不需要改决策层，只换输入端与执行器。

04

智能蒙版——从"整幅图"到"语义区域"

现在所有编辑都是对整幅图生效的，所以天空一动，人脸跟着动；要压暗背景，前景一起变暗。 这正是"稍微调一下"做不到的结构性原因：模型没有"只改这里"这个动作。

专业修图从来是局部作业。做实用化必须支持智能蒙版：由分割模型自动给出天空、人物、皮肤、 植被、背景等语义区域，编辑指令作用在指定区域上——"天空更蓝一点"只改天空， "皮肤柔和一点"只改皮肤。这既让幅度可控，也让每一步的意图可以被精确表达与验证。

工程上还有两件小事可以并行：按原分辨率分块编辑（瓦片 + 接缝融合），以及让评判模型在动手之前 就标出高风险步骤，而不是等生成完再拦。

08DISCUSSION

为什么"动作级"优化走不通，而"方向级"可行

把美感写成调色参数的函数 A(θ)，它有四个同时存在的坏性质——这正是"一个一个动作地试、分数涨了就保留" 注定失败的原因，也是 PhotoAgent 无论怎么调 MCTS 都救不回来的原因。

性质含义本文实测到的对应现象
崎岖非凸局部最优的数量随维度暴涨"调冷"一步就把整幅图推 −57；不存在可走的"小步"
强不可分单个参数单独动就难看，必须成组联动才成立只加暖 → 黄雾（+50 ~ +83）；只提亮 → 像过曝
梯度不可得只能采样，且评判本身是学习模型、带噪美学分由 VLM 给出，同一张图两次可差 0.1
度量错配优化目标与人眼感知不是一回事CLIP 相似度 0.89 的图照样凭空画出一片树叶

最致命的是第二条：很多操作只有组合起来才不怪异。这意味着好解落在参数空间里一条狭窄的脊线上， 而脊线方向不是坐标轴方向——是若干参数同向联动的方向（提亮的同时压高光、加暖的同时抬阴影）。 于是单坐标移动几乎必然掉出脊线；脊线上的点之间也不能插值：两个都成立的峰（4.2 / 4.5 分）， 中点只有 4.2，落在谷底。

这解释了 PhotoAgent 的设计为什么与问题本质冲突：原子动作把"成组联动"切成了单个动作， 而在这个空间里单个动作只有两极——不可见，或者崩坏（实测：中性锐化 Δ≈0，一带颜色词 Δ 就 ±50~80， 中间没有"适中"这一档）；单调接受又禁止了跨鞍点所需的"先变差再变好"。 结果它收敛到的不是峰，而是奖励模型平均口味附近那个最宽的盆地：偏暖、过饱和。 那是一个典型的"局部优、整体劣"解——任何沿单坐标爬坡的东西都会滑进去。

换成方向级搜索，性质就变了：一个风格方向本身就是脊线上的点，落进去基本不会掉出来 （实测结构相关性 0.99、色彩中性都发生在"明确约束的成组编辑"里）；而在同一方向内部， 只剩强度这一维，目标是局部平滑的——这才可控、可插值。再往前一步是把它彻底学掉： 既然脊线方向由"图像 + 风格"决定，就直接学一个映射 θ = f(图像, 风格)，一次前向出参数， 把搜索整个消掉。这也是"必须重训执行器"的根本理由：搜索这条路的目标函数性质太差，只有学习映射能绕开它。

这个结论不是这一件事上得到的。我之前做过一个 RAW 胶片模拟与色彩风格迁移系统（106 个可微参数 + 参考集上的风格能量模型），它的风格迁移版本失败的原因完全相同：在风格空间里做平均，输出就变灰变脏。 当时的修正是把参考集聚成 2–4 个"风格头"、每张图只路由到一个头、头间差异过大时禁止混合； 最终稳定可用的形态是逐片种从光谱数据烘焙的 3D LUT——单峰，压根没有平均这回事。 两个项目在两个抽象层级撞到同一堵墙：
